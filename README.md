# 🐍 Snake Water Gun

A simple **Snake Water Gun** game implemented in both **Python** and **Java**. This project was created to practice programming fundamentals such as user input, conditionals, random number generation, loops, and game logic.

## 🎮 How the Game Works

The game is played between the user and the computer.

* 🐍 **Snake** beats 💧 Water
* 💧 **Water** beats 🔫 Gun
* 🔫 **Gun** beats 🐍 Snake
* Same choice = **Draw**

The computer randomly selects one of the three choices, and the user enters their choice.

## 💻 Implementations

* **Python** — `snake_water_gun.py`
* **Java** — `SnakeWaterGun.java`

## 🛠️ Technologies Used

* Python
* Java

## ▶️ How to Run

### Python

```bash
python snake_water_gun.py
```

### Java

```bash
javac SnakeWaterGun.java
java SnakeWaterGun
```

## 📌 Features

* Computer generates a random choice
* User input for Snake, Water, or Gun
* Win, lose, and draw detection
* Multiple rounds
* Final result based on the overall score
